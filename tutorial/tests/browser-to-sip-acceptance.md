# 浏览器到 SIP 验收清单

本清单用于隔离实验环境。自动化信令证据不能替代人工听感；不要在记录中写入
SIP 密码、Authorization、Digest nonce、私钥、IP、电话号码、SDP 或完整 UUID。

## 环境与清理

- [ ] 教学服务只绑定 loopback，FreeSWITCH WSS 使用可信且地址匹配的证书。
- [ ] 记录浏览器、操作系统、FreeSWITCH 和 SIP.js 版本。
- [ ] 验收结束后注销浏览器分机、停止事件订阅，并清理教程生成的数据。

## 自动化或可观察信令证据

- [ ] 浏览器显示 `registered`，health 显示 WSS/SIP profile 可用。
- [ ] 呼叫 1001 后观察 `ringing`，接听后观察 `established`。
- [ ] 呼叫 5000 后发送每个课程规定的 DTMF 分支，并在事件面板看到脱敏事件。
- [ ] 挂断后观察 `terminated`，确认远端会话和本地状态均已清理。

`9000` 的教程 IVR 分支验收矩阵：

- [ ] `1` → submenu，再按 `1`，观察 `submenu/1` 事件和提示音。
- [ ] `1` → submenu，再按 `2`，观察 `submenu/2` 事件和提示音。
- [ ] `2`，观察 `main/2` 事件和提示音。
- [ ] `3`，观察 `main/3` 事件和提示音。

## 人工媒体证据

人工媒体检查必须单独记录，不能由 signaling 状态自动勾选：

- [ ] 1000 → 1001：听到对方声音。
- [ ] 1001 → 1000：听到对方声音。
- [ ] 双方各说一句话，对端能听到并且没有单向音频。
- [ ] IVR 提示音清晰，DTMF 分支后的提示音与课程预期一致。
